Running the program:
The frontend can be run by using the command "npm run dev" and going to http://localhost:5173.
The backend can be run by using the command "node index.js" while in the backend folder.
If the frontend is not running on localhost:5173, the index.js file will need to be edited to allow the localhost to access the backend.
